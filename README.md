# Lookalike Link Alert

類似文字・文字種混在・不審な URL 構造を端末内で検査する、日本語 UI の Chrome Manifest V3 拡張機能です。自前サーバー、外部 API、アカウント登録は不要です。

> URL の特徴を説明する補助ツールであり、詐欺サイトの網羅的な検出や、すべての遷移の通信前遮断を保証しません。

## できること

- キリル文字・ギリシャ文字など、英数字に似た文字と不自然な文字種の混在を検査。
- Unicode / Punycode と、本当の登録可能ドメインを並べて確認。
- URL として表示されたリンク文字と、実際の接続先を比較。
- userinfo（`@` より前の情報）、不可視文字、保護対象ドメインの類似・埋め込みなどを説明。
- HTTP、IP、非標準ポート、長さ、深いサブドメイン、一部の短縮 URL を参考情報として表示。
- 通常 / 慎重プリセット、16 項目の個別切替、閾値、ホスト例外。
- 警告からの継続を、そのタブ・その URL の GET 遷移に限定。
- URL を開かずに手動チェック。設定の JSON バックアップ・検証付き取込。

ページ内警告とツールバーポップアップでは、クリックして検査の詳細を展開できます。警告の詳細ページでは最初から表示します。詳細設定は別タブで開きます。

日本語ドメインは、日本語であることだけでは初期状態の警告を出しません。日本語のパス・検索語も同様です。類似文字や不審な混在などの別の理由は免除しません。日本語 IDN 自体の警告も有効にできます。

保護対象の正規ドメインは利用者が登録します。初期状態に完全なブランドリストや悪性サイトリストは含まれていません。文字が似ているだけで詐欺と断定する機能ではありません。

## ソースから使う

Node.js 24 系、npm、Chrome 140 以降が必要です。

```sh
npm ci
npm run build
```

1. Chrome の `chrome://extensions` を開く。
2. デベロッパーモードを有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」で `dist` を選択する。
4. 開いた設定画面で保護範囲を確認し、設定を保存する。
5. ツールバーへ固定すると、入力した URL の手動チェックに使える。入力欄は空で開き、現在のページの URL は自動入力・自動検査しない。

ツールバーメニューの「リンクの検査」スイッチで自動検査を有効・無効にできます。個別の検査項目や例外は保持されます。無効時も手動チェックは利用できます。

ビルド後にコードを更新したら再ビルドし、拡張機能管理画面から再読み込みしてください。既存ページのコンテンツスクリプトもページの再読み込みで更新してください。

拡張の再読み込み前から開いているページでは、古いスクリプトから拡張へ通信できなくなります。警告から確認画面を開く際に再読み込みの案内が出た場合は、入力中の内容を保存してから、そのページを再読み込みしてください。

## 保護範囲と制約

| 経路 | 動作 |
| --- | --- |
| 通常ページ上のトップフレーム内のリンク | コンテンツスクリプトで移動前に検査。通常クリック、キーボード、修飾キー、中クリックを対象 |
| Punycode を含む URL / userinfo を含む URL の GET 遷移 | 有効な検査に応じて DNR で拡張の検査ページへ転送。正常な候補は端末内判定後に継続 |
| DNR 条件に該当する直接入力・サーバーリダイレクト | 接続先への対象リクエスト送信前に検査 |
| ASCII の綴り違い・表示と接続先の不一致 | ページ内リンク・手動チェックで検査。すべての直接入力を事前遮断するわけではない |
| POST、iframe、ダウンロード、ブラウザ内部ページ | 自動保護の対象外。POST を GET に置き換えない |
| 右クリックメニュー、スクリプトの移動、閉じた Shadow DOM、他拡張との競合 | コンテンツ側で同じ保護を保証しない。該当する DNR ルールの保護は別 |
| シークレットモード | 非対応 |

ページ内ダイアログは利便性のための UI です。悪意あるサイトから隔離された安全境界ではありません。詳細表示と継続の操作は `chrome-extension://` の拡張ページで行ってください。

この拡張が保護できない経路、拡張無効時、Chrome の制限ページ、権限が取り消された状態では自動検査できません。ブラウザ自身のフィッシング保護と併用してください。

URL にユーザー情報が含まれる場合、警告ページからの継続はできません。正規サイトを別の信頼できる方法で開いてください。URL が 8192 文字を超える場合や解析できない場合は「未検査」と表示します。

## 権限とデータ

| 権限 | 用途 |
| --- | --- |
| HTTP / HTTPS のホストアクセス | リンク検査と DNR による対象 GET 遷移の事前検査 |
| `storage` | 端末内の設定と、一時的な確認・継続状態 |
| `declarativeNetRequest` | 疑わしい候補の事前転送、タブ・URL 限定の一時許可 |
| `webNavigation` | 遷移完了・失敗時に一時許可を破棄 |
| `alarms` | 期限切れの確認状態と一時許可を清掃 |

URL の外部送信、テレメトリー、サイトの先読み、短縮 URL の外部展開は行いません。Cookie・ブックマーク・閲覧履歴 API の権限は要求しません。[プライバシーポリシー](./PRIVACY.md)も参照してください。

## 開発と試験

```sh
npm run typecheck
npm run lint
npm test
npm run test:coverage
npx playwright install chromium
npm run build
npm run test:e2e
npm run test:chrome
npm run package
```

E2E は専用の一時ブラウザプロファイルとローカルサーバーを使用します。`.test` の名前解決をそのブラウザ内だけでループバックへ向け、実際の悪性サイトへアクセスしません。試験用 Chromium のダウンロードにはネットワークが必要です。

`test:chrome` はインストール済みの Chrome を専用プロファイルで起動します。拡張をテスト用に読み込むための Chrome デバッグ API に対応するバージョンが必要です。通常利用のプロファイルには触れません。

テストは「警告が見えた」だけでなく、ローカルサーバーの受信記録で対象 URL が警告前に受信されていないことを確認します。通常の実 Chrome でも、リリース前に手動試験を実施してください。

### 解析データ

- Unicode confusables 16.0.0 を同梱。出典・SHA-256・件数は [データ情報](./public/licenses/unicode-source.json)。
- UTS #39 の NFD と skeleton マッピングを用いた補助的な類似検査です。UTS #39 全体への準拠や網羅的な IDN セキュリティ判定を主張しません。
- PSL の ICANN / PRIVATE セクションを `tldts` を通じて利用します。PSL はドメインの実在性・安全性の判定には用いません。
- データ更新は開発時にレビューし、拡張リリースへ含めます。利用者の閲覧中にデータを取得しません。
- Unicode の更新コマンドは `npm run data:unicode`。依存データの更新時はフィクスチャとライセンスも確認してください。
